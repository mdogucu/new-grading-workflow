# STAT 100 — course assistant folder (start here)

Welcome! You'll use two Google Drive folders this semester:

1. **stat100-ca-shared** (this folder) — the dashboard app, instructions,
   rubrics and email templates. Every CA has it.
2. **stat100-grader-<your GitHub username>** — your own folder. Only you and
   the admin team can see it. The dashboard saves your grading there.

## First-time setup (about 20 minutes)

Follow these in order. Each has step-by-step instructions in `docs/`:

1. **Put both folders on your computer** — `docs/setup-computer.md`, step 1
2. **Install R packages and Git** — `docs/setup-computer.md`, steps 2–3
3. **Create and save a GitHub token** — `docs/setup-github-token.md`
4. **Open the dashboard** — open `app/app.R` in RStudio and click **Run App**
5. Go to the **Setup** tab. Everything should be green. If not, each red line
   says what to do.

## Every week

Open the dashboard. The **My tasks** page lists what you need to do and by
when, with a link to the right tab. Regrades always come first.
How grading works: `docs/how-to-grade.md`.

## Folder contents

| | |
|---|---|
| `app/` | the dashboard. Don't edit. |
| `docs/` | setup instructions and troubleshooting |
| `templates/` | email templates used by the dashboard |
| `rubrics/` | homework rubrics |
| `course-info/` | calendar, sections, staff list — kept up to date by the admin team |

Problems? Check `docs/troubleshooting.md`, then ask in the teaching-team channel.
