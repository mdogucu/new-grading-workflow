EMAIL TEMPLATES

One file per email. The dashboard fills in the {words in braces}.

Format:
  Subject: the subject line
  (blank line)
  The body...

Available everywhere: {course} {semester} {github_org} {website} {sender}
Some templates have extra ones (e.g. {assignment}, {questions}) — they are
listed at the top of the dashboard tab that uses them.

To change wording: edit the file and save. The dashboard picks it up next time.
To add a template: copy a file, rename it, edit it. (A new template only shows
up in the dashboard if a tab uses it — ask before expecting it to appear.)
